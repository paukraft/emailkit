Fires when the recipient reports a message as spam through their mail provider's feedback loop. Treat it as a hard unsubscribe: keep sending after a complaint and your sender reputation pays for it.

```ts
hooks: {
  email: {
    onComplained: async (event) => {
      await prisma.suppression.upsert({
        where: { email: event.recipient },
        create: { email: event.recipient, reason: "complaint" },
        update: {},
      });
    },
  },
},
```
