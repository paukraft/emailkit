Fires when the provider accepts a message for sending. Record the send under its `messageId` — every later event for this message ([delivered](/reference/events/email/on-delivered), [opened](/reference/events/email/on-opened), [bounced](/reference/events/email/on-bounced), …) carries the same one.

```ts
hooks: {
  email: {
    onOutbound: async (event) => {
      await prisma.sentEmail.create({
        data: {
          messageId: event.messageId,
          recipient: event.recipient,
          subject: event.subject,
          status: "sent",
        },
      });
    },
  },
},
```
