Fires when a domain is removed through `emailkit.domains.delete()`. Clean up your record — sends from its addresses will fail from here on.

```ts
hooks: {
  domain: {
    onDeleted: async ({ domain }) => {
      await prisma.sendingDomain.deleteMany({
        where: { domain: domain.domain },
      });
    },
  },
},
```
